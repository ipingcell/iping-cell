# IPING CELL Website

Website katalog paket internet dengan:
- Provider yang dapat diklik
- Filter masa aktif
- Kartu paket dan harga
- Detail paket + tombol WhatsApp
- Login admin Supabase
- Tambah, ubah, dan hapus paket

## Konfigurasi
Edit `config.js` jika project Supabase berubah.

## GitHub Pages
Upload semua file ke root repository, lalu aktifkan:
Settings → Pages → Deploy from a branch → main → /(root).

Publishable key boleh berada di browser jika Row Level Security (RLS) sudah benar. Jangan pernah menaruh Supabase Secret Key di file website.
